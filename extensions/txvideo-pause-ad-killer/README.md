# 腾讯视频暂停广告清理（浏览器扩展）

在 `v.qq.com` 看视频时，一暂停就弹出广告浮层？这个扩展会在广告出现的瞬间把它隐藏，直接露出当前视频画面。纯本地运行，不上传任何数据。

## 安装（Chrome / Edge 通用）

1. 打开浏览器的扩展管理页：
   - Chrome 地址栏输入 `chrome://extensions/`
   - Edge 地址栏输入 `edge://extensions/`
2. 打开右上角（Edge 是左侧栏）的 **「开发者模式」** 开关。
3. 点击 **「加载已解压的扩展程序」**，选择本文件夹 `txvideo-pause-ad-killer`。
4. 打开任意腾讯视频播放页，暂停一下试试 —— 广告应该一闪而过或完全不出现。

> 更新代码后，回到扩展管理页点该扩展卡片上的 **刷新 ↻** 按钮，再刷新视频页即可。

## 工作原理（三层兜底）

| 层级 | 手段 | 作用 |
| --- | --- | --- |
| 1 | CSS 兜底（`content.css`，document_start 注入） | 已知广告容器直接 `display:none`，防闪现 |
| 2 | 精确选择器（content.js） | 覆盖腾讯视频多代播放器的暂停广告节点（`txp_ad_pause` 等） |
| 3 | 启发式评分 | 类名/属性含 `ad`、文案含「广告/赞助」+ 覆盖视频画面 12% 以上 + 高层级浮层，综合打分 ≥5 才隐藏；同时保护控制条/弹幕等正常 UI |

触发时机：`video` 的 `pause` / `waiting` 事件、MutationObserver 增量监听、暂停状态下每 2 秒一次的低频轮询。广告层若把视频设为隐藏，还会顺手把画面恢复回来。

## 弹窗设置

点浏览器工具栏上的扩展图标：

- **启用清理**：总开关
- **尝试点关闭**：部分版本不点广告自带的关闭按钮会卡住播放器状态，遇到这种情况再打开（默认关，避免误触跳转）
- **调试日志**：开启后在视频页按 F12，控制台会打印每次命中的节点，便于反馈问题
- **立即清理一次**：手动触发一轮扫描

## 如果某天失效了

腾讯视频前端结构经常改版。失效时：

1. 打开弹窗里的 **调试日志**；
2. 在视频页按 F12，暂停视频，把控制台里 `[暂停广告清理]` 的输出（或没输出时，广告元素的 HTML）发给我，我可以针对性补选择器。

## 文件结构

```
txvideo-pause-ad-killer/
├── manifest.json    # MV3 配置
├── content.css      # CSS 兜底层
├── content.js       # 核心检测 + 隐藏逻辑
├── popup.html / popup.js  # 工具栏弹窗设置
├── icons/           # 图标（gen_icons.py 生成）
└── gen_icons.py     # 图标生成脚本（可删）
```

仅声明 `storage` 权限和 `v.qq.com` 的访问权限，无网络请求、无数据收集。
